## Ігрова механіка

Три короткі рівні:

1. **ЗЕЛЕНА** бульбашка — пружна платформа. Стрибни на неї, щоб підлетіти до виходу.
2. **СИНЯ** — ліфт. Стрибни зверху: бульбашка почне підніматися разом із героєм.
3. **ЧЕРВОНА** — з'єднай три поруч для вибуху, який відштовхує ящик на кнопку та відкриває вихід.

Усі кольори залишаються доступними у наступних рівнях. Комбінації з трьох однакових бульбашок лопаються та створюють ефект; червоний вибух є ключем третього рівня.

## Керування

- **Смартфон:** тап на ◀/▶ вмикає рух у цьому напрямку; повторний тап зупиняє. `СТРИБ` — стрибок. Кольорові картки перемикають бульбашки. Тап/перетягування у кімнаті → вистрілити в точку.
- **ПК:** A/D або ←/→ — рух; W/↑/Space — стрибок; 1/2/3 — колір; клік мишею — постріл; R — повтор рівня.
- Доступні 3 спроби на весь пробіг. Кнопка ↻ перезапускає поточний рівень.

## Файли

- `BubbleBuilder_GDevelop_v010.json` — **нативний GDevelop 5 проєкт**, відкрити через File → Open Project у [GDevelop](https://editor.gdevelop.io/).
- `GameScene_v010.js` — код JavaScript-події сцени у GDevelop, містить ігрове ядро.
- `GameCore_v010.js` — спільна логіка обох версій для наступних ітерацій.
- `index.html` / `docs/index.html` — браузерна демоверсія з тією ж логікою; **не офіційний експорт GDevelop**.
- `tests/` — перевірки ігрових механік, GDevelop-вбудовування й структури.
